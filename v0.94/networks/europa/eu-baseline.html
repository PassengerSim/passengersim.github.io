    Europa Baseline Network¶

    This page reviews the configuration of the Europa network and runs a baseline simulation, with all three carriers using the same revenue management system (E). See the Europa network overview for a description of the carriers and their hubs.

    import altair as alt
import passengersim as pax
from passengersim.config.checks import check_config

pax.versions()

    passengersim 0.94
passengersim.core 0.94

    cfg = pax.Config.from_yaml(pax.demo_network("europa"))

    Route Maps¶

    cfg.plotly_route_map("Brat", center_lon=31, center_lat=52, zoom=2.2)

    cfg.plotly_route_map("Stroop", center_lon=31, center_lat=52, zoom=2.2)

    cfg.plotly_route_map("Tapas", center_lon=0, center_lat=50, zoom=4.5)

    For this example page, we will pre-build the flight connections, so we can do some pre-simulation checking to review our network and verify it is constructed correctly.

    from passengersim.connection_builder import prebuild_connections

cfg = prebuild_connections(cfg, inplace=False)

    Market Pricing Distribution¶

    alt.Chart(cfg.dataframes.markets.eval("price_per_mile = lowest_fare / distance")).mark_point().encode(
    x=alt.X("distance", title="Market Distance (miles)"),
    y=alt.Y("price_per_mile", title="Lowest Fare Price per Mile", scale=alt.Scale(zero=False)),
    tooltip=["orig", "dest", "distance", "lowest_fare", "price_per_mile"],
    color="orig",
    shape="dest",
)

    Here we have plotted the lowest price fare per mile against the distance. We can see the cluster of lower priced markets with MAD origins (reflecting the LCC that is dominant there) as well as cluster of higher priced markets that are effectively controlled by legacy carriers flying into fortress hubs with zero or nearly zero competition. Note none of this is an outcome of the simulation, this is merely the input/setup of pricing for the network.
