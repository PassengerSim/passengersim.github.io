    "# Logging simulation diagnostics\n",
    "\n",
    "If you want to save periodic diagnostic records to a file, you can configure a file handler for the\n",
    "`passengersim.diagnostics` logger. This example shows how to do that, and how to read the resulting\n",
    "JSON-lines file. It is important to remember that the logger must be configured **before** the\n",
    "simulation run starts, otherwise your periodic records will simply be sent into the void, never to\n",
    "be seen.\n",
    "\n",
    "PassengerSim uses the `passengersim.diagnostics` logger and existing handlers; it does not create a\n",
    "log file for you. If that logger does not accept INFO records when the run starts, periodic\n",
    "diagnostic logging is not started.\n",
    "\n",
    "This example writes one JSON object per line to a uniquely named file, runs a small two-trial model,\n",
    "and reads the resulting records. Logging is independent of which live dashboard panels are visible.\n",
    "\n",
    "The usual PassengerSim installation and license requirements apply. See\n",
    "[periodic diagnostic logging](../user-guide/diagnostics.md#periodic-diagnostic-logging) for the full\n",
    "configuration and record descriptions."
   ]

    "## Install the file handler before running\n",
    "\n",
    "Each diagnostic LogRecord that PassengerSim will emit has a `diagnostics` dictionary. This formatter\n",
    "saves that dictionary without rounding its numeric values and adds a UTC timestamp. The filter keeps\n",
    "unrelated messages out of the JSON-lines file. Other than knowing that there will be a `diagnostics`\n",
    "dictionary in the LogRecord, nothing in the following code block is PassengerSim-specific, it is\n",
    "just regular Python logging semantics."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "3320a9d2",
   "metadata": {},
   "outputs": [],
   "source": [
    "class DiagnosticJSONFormatter(logging.Formatter):\n",
    "    \"\"\"Serialize diagnostic records with an explicit UTC timestamp.\"\"\"\n",
    "\n",
    "    def format(self, record: logging.LogRecord) -> str:\n",
    "        payload = dict(record.diagnostics)\n",
    "        payload[\"timestamp\"] = datetime.fromtimestamp(record.created, UTC).isoformat()\n",
    "        return json.dumps(payload)\n",
    "\n",
    "\n",
    "log_directory = Path(\"diagnostic-logs\")\n",
    "log_directory.mkdir(parents=True, exist_ok=True)\n",
    "log_path = log_directory / f\"run-{uuid4().hex[:12]}.jsonl\"\n",
    "\n",
    "diagnostic_logger = logging.getLogger(\"passengersim.diagnostics\")\n",
    "previous_level = diagnostic_logger.level\n",
    "previous_propagate = diagnostic_logger.propagate\n",
    "file_handler = logging.FileHandler(log_path, encoding=\"utf-8\")\n",
    "file_handler.setLevel(logging.INFO)\n",
    "file_handler.setFormatter(DiagnosticJSONFormatter())\n",
    "file_handler.addFilter(lambda record: hasattr(record, \"diagnostics\"))\n",
    "\n",
    "diagnostic_logger = logging.getLogger(\"passengersim.diagnostics\")\n",
    "diagnostic_logger.addHandler(file_handler)\n",
    "diagnostic_logger.setLevel(logging.INFO)\n",
    "diagnostic_logger.propagate = False"
   ]
  },

    "    file_handler.close()\n",
    "    diagnostic_logger.setLevel(previous_level)\n",
    "    diagnostic_logger.propagate = previous_propagate\n",
    "\n",
    "print(f\"Diagnostic records saved to {log_path.resolve()}\")"

    "## Inspect the log\n",
    "\n",
    "The last record contains the final available snapshot and completion status. Timing values are\n",
    "summed worker seconds, which can exceed elapsed wall time for parallel runs. Carrier counts exclude\n",
    "burn-in; `completed_samples` includes it. Confidence-interval half-widths are `null` until 30\n",
    "post-burn-in observations are available for a carrier.\n",
    "\n",
    "Periodic records can contain older worker observations during a long operation; inspect\n",
    "`snapshot_age_seconds` and the ages in `active_trials` when interpreting them. Database sizes\n",
    "include each main file and its journal/WAL/SHM companions. Files may disappear as temporary\n",
    "databases are consolidated or cleaned up.\n",
    "\n",

    "## Adjust logging for the next run\n",
    "\n",
    "Use `cfg.simulation_controls.diagnostics.log_interval = 60` for the default cadence, or set it to\n",
    "`None` to disable diagnostic logging while retaining other diagnostics. Setting\n",
    "`cfg.simulation_controls.diagnostics.mode = \"off\"` disables both collection and diagnostic logging.\n",
    "Changing `.mode` back to `\"live\"` keeps the logging interval and panel settings.\n",
    "\n",
    "Assigning a shorthand to the entire `diagnostics` setting, such as `\"full\"` or `\"off\"`, resets its\n",
    "other options, including the interval. Set the interval afterward if needed. For another run with\n",
    "file logging, rerun both the handler and run cells above so logging is configured again before the\n",
    "simulation starts."
