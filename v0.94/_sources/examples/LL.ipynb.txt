  {
   "cell_type": "markdown",
   "metadata": {},
   "source": [
    "From the carrier's perspective, clearly something is wrong. While customers will only purchase the\n",
    "lowest available fare, we would expect that carriers would want to optimize their networks by\n",
    "sometimes making the lowest *available* fare not actually the lowest *possible* fare.\n",
    "\n",
    "The problem in this case is in the use of standard class-based forecasting. These forecasts assume\n",
    "demand for each fare class is independent, and that we can forecast the level of demand for each\n",
    "fare class based on the historical demand for that fare class. But in our simulation that gets us\n",
    "into a catch-22: the lack of sales in higher classes results in forecasting zero demand for those\n",
    "higher classes, and that zero forecast means the optimizer never closes the lowest fare class to try\n",
    "to save space for higher class customers (because it thinks there aren't any).\n",
    "\n",
    "To solve this problem, we need to use a different kind of forecast, which accounts for the\n",
    "propensity for at least some customers to buy up to a higher fare class if the class they prefer is\n",
    "closed. The RM system \"L\" uses the same leg-based optimizer as \"E\", but instead of using standard\n",
    "forecasting it switches to conditional forecasting, which relaxes the independent demands by fare\n",
    "class assumption, and instead assumes that customers who purchase the lowest available fare are\n",
    "\"priceable\" customers, and that some fraction of those customers will still buy if the fare were\n",
    "higher. This fraction changes over the booking horizon, with generally lower fractions for early\n",
    "bookings and higher fractions for late bookings; how large that fraction is and how it changes over\n",
    "time is decribed by a \"Frat5 curve\", which we will ascribe to each carrier."
   ]
  },
