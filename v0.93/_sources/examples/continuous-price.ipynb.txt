    "# Continuous Pricing\n",
    "\n",
    "In this example, we will use class-based continuous pricing (CBC) in the\n",
    "three-market demo network. With discrete pricing, a carrier offers fares from\n",
    "a fixed set of booking classes. Continuous pricing allows the offered price\n",
    "to vary between those fares, while still using booking classes to record sales\n",
    "and forecast demand.\n",
    "\n",
    "We will compare a baseline with three ways of recording continuously priced\n",
    "sales. Only AL1 will use continuous pricing, so we can also see how its pricing\n",
    "decisions affect its competitor, AL2."
   ]

   ]
  },
  {
   "cell_type": "markdown",
   "id": "8ef0de8b",
   "metadata": {},
   "source": [
    "For the other three experiments, we enable CBC for AL1 and leave AL2 without\n",
    "continuous pricing. CBC combines the path's bid price with a willingness-to-pay\n",
    "adjustment based on the Frat5 curve. All three scenarios use the same pricing\n",
    "algorithm and scale; what changes is how sales and availability are recorded\n",
    "for forecasting.\n",
    "\n",
    "- `cbc_highestclosed_as_open` records continuously priced sales in the highest\n",
    "  closed class and treats that class as open in the recorded availability history.\n",
    "- `cbc_highestclosed` records sales in the same class but retains its ordinary\n",
    "  closed status in the history. This will lead to the forecast for that class being \n",
    "  higher than otherwise, as detruncation will apply.\n",
    "- `cbc_lowestopen` records sales in the lowest open class, with no corresponding\n",
    "  change to availability history.\n",
    "\n",
    "The `cp_record_highest_closed_as_open` flag affects history recording, not the\n",
    "price calculation at the time of an offer. However, the resulting history can\n",
    "change later forecasts and bid prices, so these choices can affect revenue as\n",
    "well as the reported class mix."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "e2769128",
   "metadata": {},
   "outputs": [],
   "source": [
    "@ex\n",
    "def cbc_highestclosed_as_open(cfg):\n",
    "    cfg.carriers.AL1.cp_algorithm = \"CBC\"\n",
    "    cfg.carriers.AL1.cp_record = \"highest_closed\"\n",
    "    cfg.carriers.AL1.cp_record_highest_closed_as_open = True\n",
    "    cfg.carriers.AL1.cp_scale = fa_scale\n",
    "    # The `cp_scale` must match the fare adjustment scale used by the RM system.\n",
    "    # This example the Qu system, which has a default scale of 0.5.\n",
    "    return cfg\n",
    "\n",
    "\n",
    "@ex\n",
    "def cbc_highestclosed(cfg):\n",
    "    cfg.carriers.AL1.cp_algorithm = \"CBC\"\n",
    "    cfg.carriers.AL1.cp_record = \"highest_closed\"\n",
    "    cfg.carriers.AL1.cp_record_highest_closed_as_open = False\n",
    "    cfg.carriers.AL1.cp_scale = fa_scale\n",
    "    return cfg\n",
    "\n",
    "\n",
    "@ex\n",
    "def cbc_lowestopen(cfg):\n",
    "    cfg.carriers.AL1.cp_algorithm = \"CBC\"\n",
    "    cfg.carriers.AL1.cp_record = \"lowest_open\"\n",
    "    cfg.carriers.AL1.cp_scale = fa_scale\n",
    "    return cfg"
   ]
